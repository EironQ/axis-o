## 四、订单管理

| 任务名称 | 描述 | 优先级 | 状态 |
|---------|------|:---:|:---:|
| 订单列表页面 | `/admin/orders` 订单列表，支持状态筛选 | P0 | 📋 |
| 订单详情页面 | 查看订单完整信息 | P0 | 📋 |
| 订单状态更新 | 更新订单状态（待发货→已发货→已完成） | P0 | 📋 |
| 发货管理 | 填写物流信息 | P1 | 📋 |
| 退款/取消订单 | 处理用户退款申请 | P1 | 📋 |

### 订单状态流转
```
pending（待付款）→ paid（已付款）→ processing（处理中）
→ shipped（已发货）→ delivered（已送达）→ completed（已完成）

取消状态：cancelled（已取消）
退款状态：refunding（退款中）→ refunded（已退款）
```

## 📁 页面路由规划

```
/admin/login              - 管理员登录
/admin/dashboard          - 仪表盘
/admin/products           - 商品列表
/admin/products/new       - 新增商品
/admin/products/:id/edit  - 编辑商品
/admin/orders             - 订单列表
/admin/orders/:id         - 订单详情
/admin/users              - 用户列表
/admin/users/:id          - 用户详情
/admin/categories         - 分类管理
/admin/settings           - 系统设置
```

## 🔌 后端 API 规划

```
认证相关
POST   /api/admin/login          - 管理员登录
POST   /api/admin/logout         - 管理员登出
GET    /api/admin/profile         - 获取管理员信息

仪表盘
GET    /api/admin/dashboard/stats     - 获取统计数据

商品管理
GET    /api/admin/products            - 商品列表
POST   /api/admin/products            - 新增商品
GET    /api/admin/products/:id        - 商品详情
PUT    /api/admin/products/:id        - 更新商品
DELETE /api/admin/products/:id        - 删除商品
PATCH  /api/admin/products/:id/status - 更新商品状态

订单管理
GET    /api/admin/orders              - 订单列表
GET    /api/admin/orders/:id          - 订单详情
PATCH  /api/admin/orders/:id/status   - 更新订单状态
PATCH  /api/admin/orders/:id/ship     - 订单发货

用户管理
GET    /api/admin/users               - 用户列表
GET    /api/admin/users/:id           - 用户详情
PATCH  /api/admin/users/:id/status   - 更新用户状态

分类管理
GET    /api/admin/categories          - 分类列表
POST   /api/admin/categories          - 新增分类
PUT    /api/admin/categories/:id      - 更新分类
DELETE /api/admin/categories/:id       - 删除分类

统计报表
GET    /api/admin/stats/sales         - 销售统计
GET    /api/admin/stats/orders        - 订单统计
GET    /api/admin/stats/users         - 用户统计
GET    /api/admin/stats/products      - 商品排行
```

---

## 📝 备注

- 所有 `/api/admin/*` 接口需要管理员 token
- 超级管理员可以管理普通管理员
- 敏感操作（如删除）需要二次确认
- 操作日志记录（可选）
